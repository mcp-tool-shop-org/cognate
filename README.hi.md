<p align="center"><strong>स्वायत्त बुद्धिमत्ता के लिए संरचनात्मक शासन।</strong></p>

कॉग्नेट, [एटटेस्टिया](https://github.com/mcp-tool-shop-org/attestia) पर निर्मित कृत्रिम बुद्धिमत्ता (एआई) शासन परत है। एटटेस्टिया यह साबित करता है कि कोई घटना घटी — कोई घटना, कोई लेनदेन, कोई अवस्था परिवर्तन — और उस प्रमाण को एक श्रृंखला से जोड़ता है। कॉग्नेट उन समान प्रमाणीकरण तत्वों का उपयोग एआई प्रणालियों को नियंत्रित करने के लिए करता है: किसी मॉडल को क्या करने की अनुमति दी गई थी, उसने वास्तव में क्या किया, और किसने इसे अधिकृत किया।

समान मूल से उत्पन्न होने वाले तत्व एआई की सच्चाई की पुष्टि करते हैं: मॉडल की उत्पत्ति, नीतिगत निर्णय, एजेंट की क्षमताएं, और संकेत और आउटपुट की अखंडता। समान मर्कल प्रमाण। समान केवल-जोड़ने योग्य घटना भंडार। अलग डोमेन।

एटटेस्टिया, कॉग्नेट और रिपोमेश तीन उत्पाद हैं। एटटेस्टिया उन बुनियादी तत्वों के आधार पर वित्तीय डोमेन (व्यक्तिगत तिजोरी, संगठनात्मक खजाना, रजिस्टर) प्रदान करता है। रिपोमेश रिलीज नेटवर्क है: हस्ताक्षरित घटनाएं, नोड मेनिफेस्ट और एक एक्सआरपीएल-आधारित ट्रस्ट क्लॉक, जो अपने स्वयं के आरएफसी 6962 लेजर पर आधारित है। यह एटटेस्टिया के मर्कल ट्री का उपयोग नहीं करता है। जब कॉग्नेट को किसी प्रमाण की आवश्यकता होती है, तो वह एटटेस्टिया को कॉल करता है, और जब रिपोमेश को किसी रिलीज की जांच करने की आवश्यकता होती है, तो वह रिपोमेश को कॉल करता है। `@cognate/repomesh-bridge` वह जांच है।

## मिशन

हमारा मानना ​​है कि जैसे-जैसे एआई सिस्टम स्वायत्तता प्राप्त करते हैं, उन्हें नियंत्रित करने वाली संरचनाओं को अधिक कठोर होना चाहिए। स्मार्ट अनुबंध निष्पादित होते हैं। मॉडल अनुमान लगाते हैं। लेकिन कोई भी यह *सत्यापित* नहीं करता है कि एआई को क्या करने की अनुमति दी गई थी, उसने वास्तव में क्या किया, और क्या किसी मानव ने इसकी मंजूरी दी।

कॉग्नेट वह लापता परत है: मॉडल रजिस्ट्री, नीति प्रवर्तन, एजेंट पहचान और नियतात्मक ऑडिट - मॉडल, संगठनों और श्रृंखलाओं में एकीकृत।

### हम किस चीज के लिए खड़े हैं

- **गति से अधिक सत्य।** प्रत्येक मॉडल अनुमान केवल-अतिरिक्त, पुन: चलाने योग्य और सुलह करने योग्य है। यदि इसे साबित नहीं किया जा सकता है, तो यह नहीं हुआ।
- **मानव अनुमोदन करते हैं; मशीनें सत्यापित करती हैं।** एआई सलाह देता है, मॉडल अनुमान लगाते हैं, लेकिन बिना स्पष्ट मानव प्राधिकरण के कुछ भी तैनात या कार्य नहीं करता है। कभी नहीं।
- **संरचनात्मक शासन, न कि राजनीतिक शासन।** हम इस पर मतदान नहीं करते हैं कि क्या मान्य है। हम अपरिवर्तनीयता को परिभाषित करते हैं जो बिना शर्त लागू होती है - मॉडल पहचान स्पष्ट है, वंश निर्बाध है, नीति संस्करण एकदिष्ट है।
- **इरादा निष्पादन नहीं है।** यह घोषणा करना कि एक एजेंट को क्या करना चाहिए और उसे कार्य करने देना, अलग-अलग कार्य हैं जिनमें अलग-अलग गेट हैं। उनके बीच का अंतर वह जगह है जहां विश्वास मौजूद है।
- **मॉडल गवाह हैं, प्राधिकरण नहीं।** एटटेस्टिया सत्यापित करता है। श्रृंखलाएं निपटान करती हैं। लेकिन प्राधिकरण संरचनात्मक नियमों से प्रवाहित होता है, न कि किसी भी मॉडल के भार से।

## त्वरित शुरुआत

```bash
pnpm install
pnpm verify        # build + test + typecheck
pnpm test:coverage # full coverage report
```

एक नीति का मूल्यांकन करें। इंजन स्थिति प्राप्त नहीं करता है। आप नीति और संदर्भ पास करते हैं।

```ts
import { evaluatePolicy } from "@cognate/policy";

const result = evaluatePolicy(policy, context);
if (result.overall === "deny") {
  // block the request
}
```

किसी मॉडल संस्करण को पंजीकृत करें, फिर उसे जीवनचक्र के माध्यम से चलाएं। एक संस्करण `registered → evaluated → approved → deployed` में आगे बढ़ता है, और यह `rejected` या `retired` हो सकता है। `transitionVersion` उस स्नैपशॉट को आगे बढ़ाता है जो कॉलर के पास है। HTTP सर्वर पर, `approved → deployed`, `repo` और `release` पर `verifyRelease` को कॉल करता है, जो उस समय रिकॉर्ड किए गए थे जब संस्करण पंजीकृत किया गया था। एक रिलीज़ जो सफल नहीं होती है, वह तैनात नहीं होती है, और न ही कोई ऐसी अनुरोध जो किसी भिन्न रिलीज़ का नाम देती है। अस्वीकृति को रिकॉर्ड किया जाता है।

```ts
import { createRegistry, registerModel, registerVersion, transitionVersion } from "@cognate/model-registry";
```

## डॉकर

छवि `@cognate/node` चलाती है और शासन API प्रदान करती है। `/health` वापस करता है:

```json
{ "status": "ok", "service": "cognate", "mode": "api" }
```

```bash
docker compose up -d
curl http://localhost:4000/health
docker compose down
```

`cognate-data` वॉल्यूम `/app/data` पर माउंट किया गया है। इवेंट लॉग `/app/data/events.jsonl` है। स्नैपशॉट `/app/data/cognate/registry.json`, `/app/data/cognate/agents.json` और `/app/data/cognate/prompts.json` हैं। एटटेस्टिया की कंपोज़ अपने स्वयं के वॉल्यूम पर समान इवेंट-लॉग चर का उपयोग करती है। प्रत्येक फ़ाइल में एक लेखक होता है। रेपोमेश की छवि इस लॉग को माउंट नहीं करती है। `REPOMESH_FAIL_ON` का डिफ़ॉल्ट मान `unverified` है: केवल एक PASS तैनात होता है। इसे `fail` पर सेट करें ताकि एक UNVERIFIED रिलीज़ को भी अनुमति दी जा सके। छवि एक लेज़र URL सेट नहीं करती है। जब GitHub पर एक रिलीज़ प्रकाशित की जाती है, तो छवि को GHCR पर प्रकाशित किया जाता है।

## खतरा मॉडल

कॉग्नेट निम्नलिखित खतरे मॉडल को मानता है:

1. **समझौता किया गया अनुमान समापन बिंदु।** एक हमलावर मॉडल एपीआई तक पहुंच प्राप्त करता है। शमन: सभी प्रॉम्प्ट और आउटपुट एन्क्रिप्टेड पेलोड और SHA-256 अखंडता हैश के साथ लॉग किए जाते हैं। पुन: प्ले नियतात्मक है।
2. **चुराए गए क्रेडेंशियल्स वाला दुष्ट एजेंट।** किसी एजेंट की कुंजियाँ लीक हो जाती हैं। शमन: क्षमताएं समय-बद्ध, दायरे-सीमित और रद्द करने योग्य हैं। प्रत्येक अनुदान के लिए स्पष्ट अनुमोदन की आवश्यकता होती है।
3. **आपूर्ति-श्रृंखला मॉडल छेड़छाड़।** मूल्यांकन के बाद भार या कॉन्फ़िगरेशन बदल दिए जाते हैं। शमन: मॉडल रजिस्ट्री पंजीकरण पर भार, कॉन्फ़िगरेशन और मेनिफेस्ट को हैश करता है। किसी भी विचलन से संस्करण अमान्य हो जाता है।
4. **प्रॉम्प्ट इंजेक्शन के माध्यम से नीति बाईपास।** एक प्रतिकूल प्रॉम्प्ट सामग्री नियमों को दरकिनार करने का प्रयास करता है। शमन: नीति मूल्यांकन नियतात्मक, संस्करणित है, और अनुमान से पहले चलता है। कोई भी प्रॉम्प्ट पासिंग नीति जांच के बिना निष्पादित नहीं होता है।
5. **ऑडिट लॉग का अंदरूनी दुरुपयोग।** एक विशेषाधिकार प्राप्त ऑपरेटर लॉग के साथ छेड़छाड़ करता है। शमन: घटना भंडार केवल-अतिरिक्त है और एटटेस्टिया के मर्कल-ट्री प्रमाणों द्वारा समर्थित है। छेड़छाड़ श्रृंखला हैश को तोड़ देती है।

कोई टेलीमेट्री या विश्लेषण नहीं। HTTP सर्वर पर एक परिनियोजन रेपोमेश से पूछता है कि क्या नामित रिलीज़ सफल है। स्वास्थ्य और अन्य मार्ग इस प्रक्रिया पर बने रहते हैं।
